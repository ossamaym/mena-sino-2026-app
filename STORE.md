# Put MENA-SINO 2026 on the App Store and Google Play

The app is ready as an installable web app. Neither store will accept a zip from this chat. Listing needs your developer accounts.

## Accounts (you must open these)
- Apple Developer Program: https://developer.apple.com/programs/ — 99 USD per year. Enrollment from Egypt can take a few days.
- Google Play Console: https://play.google.com/console — 25 USD once.

## Fastest path for both stores
1. Host this folder on a public HTTPS URL (Vercel or GitHub Pages).
2. Open https://www.pwabuilder.com and paste that URL.
3. Package for Android (Google Play) and iOS (App Store). PWABuilder produces the store packages.
4. Upload the Android package in Play Console. Upload the iOS package in App Store Connect (a Mac or a cloud Mac build is still required for the final Apple signing step).

## Listing
- Name: MENA-SINO 2026
- Subtitle: Luxor congress programme
- Bundle id: com.menasino.programme
- Category: Medical
- Age: 4+ / Everyone
- Privacy policy URL: host privacy.html and paste that URL in both consoles
